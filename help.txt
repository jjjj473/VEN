VEN Web Editor Commands

:w [file]    Save the buffer. Optionally provide a file name.
:q           Close the browser window (prompts for confirmation).
:o [file]    Open a local file.
:new         Clear the editor buffer.
:help        Show this help text.
:goto N      Jump to line N.
:replace A B Replace text A with B globally.
:undo        Undo last change.
:redo        Redo last undone change.
:cut         Cut selected text to clipboard.
:copy        Copy selected text to clipboard.
:paste       Paste clipboard at cursor.
:find TEXT   Search for TEXT and select next occurrence.
:selectall   Select the entire buffer.
:fontsize +/- Increase or decrease editor font size.
:numbers     Toggle line numbers.
:preview     Open buffer contents in a new tab.
