# VEN Web Editor

VEN is a browser-based code editor built with HTML, CSS and JavaScript.
It uses the [CodeMirror](https://codemirror.net/) library to provide syntax
highlighting and other modern editor features in a simple graphical interface.

## Features

- Syntax highlighted editing for JavaScript, HTML and CSS
- Toolbar buttons for common actions (New, Open, Save, Help) and utilities like
  Undo, Redo, Cut, Copy, Paste, Find, Replace, Goto, Select All, font size
  adjustment, toggling line numbers and previewing the buffer
- Secondary toolbar with advanced controls for line wrapping, theme switching,
  viewing document statistics, and showing an About dialog
- Status bar indicating current line, column and file name
- File open and save using the browser's file APIs
- Help dialog describing available tools

## Usage

Open `index.html` in any modern web browser. No build step is required. Use the
toolbar buttons for all operations. Prompts will appear for tasks such as find,
replace, and going to a specific line. The advanced toolbar lets you toggle
line wrapping, switch between light and dark themes, view statistics about the
current document, preview the file in a new tab and open the About dialog.

This is a simple prototype and contributions are welcome.
